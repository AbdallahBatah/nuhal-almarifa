# نُهال المعرفة للتدريب والتطوير — الموقع الإلكتروني

موقع ثابت (HTML/CSS/JS) لشركة **Nuhal Almarifa Training & Development L.L.C** في دبي، باللغة العربية واتجاه RTL.

## الصفحات
`#home` الرئيسية · `#about` عن الشركة · `#programs` البرامج التدريبية · `#accreditations` الاعتمادات · `#team` الفريق · `#experience` الخبرات

## الهيكل
```
index.html          الصفحة كاملة (التصميم + البيانات + السكربت)
assets/img/         صور الموقع (من بروفايل الشركة)
assets/favicon.svg  أيقونة المتصفح من شعار الشركة
```

## التشغيل
لا يحتاج أي بناء أو تثبيت: افتح `index.html` في المتصفح، أو ارفع المجلد كما هو على أي استضافة (GitHub Pages أو Netlify أو cPanel).

**GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / root.

## تحديث تقويم البرامج
بيانات البرامج داخل `index.html` في المتغير `const ITEMS = [...]`. كل برنامج بالشكل:
```js
{"t":"عنوان البرنامج","tr":0,"m":11,"d1":8,"d2":12,"c":"دبي"}
```
- `tr` رقم المسار (0 القيادة · 1 التحول الرقمي · 2 الابتكار · 3 البيانات والأمن السيبراني · 4 المهارات المستقبلية · 5 الذكاء الاصطناعي الحكومي · 6 المالية والمحاسبة)
- `m` الشهر، `d1` و`d2` يوم البداية والنهاية، `c` المدينة

حالة كل برنامج (متاح / قيد الانعقاد / منعقد) تُحسب تلقائياً من تاريخ اليوم.

## قبل الإطلاق
- **النماذج** (التسجيل وطلب برنامج) تجهّز نص الطلب للنسخ فقط، ويجب ربطها بالبريد أو بنظام CRM عند النشر على nuhal.ae.
- **صفحة الفريق** مبنية على الأدوار، وتُضاف الأسماء والصور عند توفرها.
- **ذكر بلدية دبي** في صفحة الخبرات يحتاج موافقة على عرض اسم الجهة.
- **الاعتمادات:** ترخيص KHDA مؤكد من البروفايل، أما بقية بنود الجودة فتحتاج اعتماد الإدارة.
